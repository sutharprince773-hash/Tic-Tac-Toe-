# AI Tic-Tac-Toe Game

## About the Project
AI Tic-Tac-Toe is a Python-based Artificial Intelligence mini project where a human player competes against an intelligent computer opponent using the Minimax Algorithm.

## Features
- Human vs AI gameplay.
- Intelligent decision-making.
- Minimax Algorithm implementation.
- Automatic win and draw detection.
- Invalid move prevention.

## Technologies Used
- Python 3
- Artificial Intelligence
- Minimax Algorithm

## How to Run

1. Clone this repository:
```bash
git clone (https://github.com/sutharprince773-hash/Tic-Tac-Toe-)
```

2. Open the project folder.
3. Run the program:
```bash
python tic_tac_toe.py
```

## How to Play
- Human player: X
- AI player: O
- Enter a number from 1 to 9 to select a square.
- The game ends when someone wins or the match is drawn.
